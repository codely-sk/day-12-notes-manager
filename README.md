# Day 12 – Notes Manager 📝

## About the Project
The Notes Manager is a Python application that allows users to create, view, search, and delete personal notes. Each note is saved as a separate text file, so the notes remain available after the program closes.

## Features
- Create notes with a title and content
- View all saved notes
- Search notes by title or keyword
- Delete unwanted notes
- Store notes permanently in text files
- Validate note titles and menu choices

## Concepts Used
- File handling
- `open()` and `read()`
- `write()` and `os.remove()`
- `os.listdir()`
- Lists and loops
- Functions and conditions
- String searching
- The `os` module

## What I Learned
- How to create and manage text files using Python
- How to save and read information from files
- How to search for keywords in saved content
- How to list and delete files
- How to organize a program using functions

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `day_12_notes_manager.py`.
4. Create notes and explore the available options.

## Storage
Notes are stored as individual `.txt` files inside the `saved_notes` folder.
